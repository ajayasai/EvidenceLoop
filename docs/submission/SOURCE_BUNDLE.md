# Source bundle for review

The local source ZIP is generated by `scripts/package_submission.py`. It is a review artifact; creating it does not publish a repository, deploy the application or submit an entry.

On 14 October the user separately authorized publication, free deployment and form uploads. [GitHub source](https://github.com/ajayasai/EvidenceLoop) was published at initial commit `6f1b125`. Render reports Live at that commit; its [public FERN journey](https://evidenceloop-aj-001.onrender.com/) through consented save/check-in and hosted video playback were verified in Chrome. The corrected [public CI run](https://github.com/ajayasai/EvidenceLoop/actions/runs/38530016145) at `f51c764` and separate public API checks passed. Rebuilding this local archive does not update the public repository or complete the competition form.

From the project root, run:

```powershell
.venv\Scripts\python.exe scripts/package_submission.py
```

Outputs are `artifacts/submission-20261014/source/EvidenceLoop-source.zip`, its JSON checksum manifest and `SHA256SUMS.txt`. Rebuild after the final source, documentation and evaluation changes. The archive contains one `EvidenceLoop` directory; start with its `README.md` and the current submission documents.

The explicit allowlist includes application code, contracts, tests, setup and evaluation scripts, locked dependencies, source evidence packets, Markdown documentation, submission CSV template and the four reviewed WorkBuddy screenshots. It also explicitly includes the reviewed public video page `apps/web/public/demo-video.html` and its three deployment assets under `apps/web/public/demo/`: the byte-identical `EvidenceLoop-recorded-walkthrough.mp4`, converted `EvidenceLoop-recorded-walkthrough.vtt` captions and `cover.png`. Private configuration, local databases, installed dependencies, caches, models, downloaded PDFs, other generated media and raw evaluation prediction logs are excluded.

The original extraction corpus and the already inspected October next partition are included as developer-authored fictional regression material so scorer tests remain reproducible. Final/challenge inputs and gold labels remain outside this source archive; their freeze metadata may be included. Aggregate scores preserve their original historical labels, so read them alongside the dated verification reports. Neither model testing nor sponsor code review establishes clinical validation. Later qualification does not retroactively make an inspected partition unseen.

Before writing the ZIP, the script checks selected file bytes against known local credentials from private project environment files and the local database credential store, without printing those values. It rejects linked source paths, oversized files and private runtime paths. It verifies ZIP CRCs, each entry's SHA-256 and that selected source files did not change during packaging. These checks cover known credentials and explicit paths; they are not a universal secret or personal-information detector. The four sponsor screenshots were separately reviewed before inclusion.

Files are sorted, with fixed ZIP timestamps and permissions. Unchanged selected bytes produce an identical archive with the same Python/zlib implementation. `BUNDLE_MANIFEST.json` inside the ZIP records every selected source file's size and SHA-256; the external manifest also records the ZIP's checksum and verification time. The manifest does not include its own checksum recursively.

The source ZIP remains separate from the submission presentation package; only the explicitly reviewed public video deployment assets above are included. Other generated decks, PDFs, recordings and their working files remain excluded. Links in historical documents to omitted private inputs or generated artifacts may not resolve inside the source archive. Application setup and the public engineering tests use the included files; no account key or paid service is required for the fictional replay workflow. The public mode permits supplied fictional examples only, disables live AI and reviewer controls, and uses ephemeral records that may reset on free-host restart.
